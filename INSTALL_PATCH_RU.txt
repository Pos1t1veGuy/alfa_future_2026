УСТАНОВКА ИЗМЕНЕНИЙ ALFA

1. Распакуйте содержимое архива поверх рабочей копии Git-репозитория (папка alfa_git), сохранив структуру папок.
2. Не удаляйте backend/hack2026_site/core/migrations/0001_initial.py — эту миграцию вы создали ранее локально.
3. В терминале из папки репозитория выполните:
   docker compose up --build -d
4. Проверьте запуск:
   docker compose ps
   docker compose logs --tail=80 backend
5. Откройте http://localhost и войдите клиентом, у которого есть заявка со статусом «Нужны уточнения».

Что изменено:
- клиент может прикрепить PDF/JPG/PNG к заявке, когда банк запросил уточнения;
- клиент может отправить приложенные документы в банк; статус переходит в «Рассматривается», в историю добавляется запись и банковским сотрудникам отправляются уведомления;
- в клиентском кабинете отказ отображается красным крестиком, запрос уточнений — янтарным значком, одобрение — зелёной галочкой;
- поправлено расположение фильтров очереди заявок, включая мобильный экран.

Поддерживаются PDF, JPG, PNG до 10 МБ на файл.
